# 产线 OEE 分析与瓶颈识别系统

基于工业 4.0 真实产线传感器数据，利用 Python 实现 OEE 指标建模、瓶颈自动诊断与工艺参数质量预警的数字化看板系统。

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 数据处理 | Pandas | 数据清洗、字段标准化、OEE 三维指标计算 |
| 可视化 | Streamlit + Plotly | 多页面交互式数字化看板，仪表盘 / 柱状图 / Pareto 图 / 雷达图 |
| 数据源 | UCI AI4I 2020 | 10,000 条真实预测性维护传感器日志 |

## 核心功能

### 生产运营总览

- 仪表盘展示 H / M / L 三条产线的 OEE 评分
- 分组柱状图对比 Availability、Performance、Quality、OEE 四项指标
- 明细表格展示故障次数、换刀次数、缺陷数

### 瓶颈工序诊断

- 自动定位 OEE 最低的产线及核心瓶颈指标（A / P / Q 中最差项）
- Pareto 双轴图：柱状频次 + 累计折线，A 类主因（80% 分界线以内）红色高亮
- 五大失效模式（HDF / OSF / PWF / TWF / RNF）各附 IE 改善建议

### 实时工艺参数模拟器

- 三个滑动条调节环境温度（290-310K）、转速（1000-2800rpm）、扭矩（10-80Nm）
- z-score 异常度评分，仪表盘实时展示风险分值（0-100）
- 绿 / 黄 / 红三级风险预警 + 雷达图可视化各参数偏离

## OEE 计算模型

| 指标 | 公式 | 计算规则 |
|------|------|----------|
| Availability | (计划时间 - 停机损失) / 计划时间 | 故障停机 30 分钟/次；刀具磨损每 200 分钟触发 45 分钟换刀 |
| Performance | 实际转速 / 标准转速 | 标准转速 1500 rpm，上限截断为 1.0 |
| Quality | (总产量 - 缺陷数) / 总产量 | TWF / HDF / PWF / OSF 任意为 1 即判定为缺陷件 |

计划时间：1440 分钟（24 小时 / 台 / 日）

## 数据源

UCI AI4I 2020 Predictive Maintenance Dataset — 10,000 条真实数字化车间运行日志，包含设备转速、扭矩、温度、刀具磨损及五类失效模式标签。
