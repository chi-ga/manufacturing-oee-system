# 产线 OEE 分析与瓶颈识别系统

基于工业 4.0 真实产线传感器日志，利用 Python 进行数据清洗、OEE 指标建模、瓶颈自动诊断与工艺参数质量预警的数字化看板系统。

## 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 数据处理 | Pandas | 数据清洗、字段标准化、OEE 指标计算 |
| 可视化看板 | Streamlit + Plotly | 多页面交互式数字化看板 |
| 数据源 | UCI AI4I 2020 | 10,000 条真实预测性维护传感器日志 |

## 快速启动

```bash

# 2. 启动数字化看板

# 3. 浏览器访问 http://localhost:8501
```


## 核心功能

### 页面 1：生产运营总览

- 顶部 `st.metric` 动态展示全线 OEE、Availability、Performance、Quality
- 产线对比柱状图，一眼识别 H/M/L 三条产线的效率差异
- 明细数据表展示故障次数、换刀次数、缺陷数

### 页面 2：瓶颈工序诊断

- 自动标红定位 OEE 最低的产线及核心瓶颈指标
- 失效模式 Pareto 图（柱状 + 累计折线双轴），覆盖 HDF/OSF/PWF/TWF/RNF 五大失效模式
- IE 智能改善建议：根据 Pareto 排序自动触发，A 类主因高亮标注

### 页面 3：实时工艺参数模拟器

- 3 个滑动条调节环境温度（290-310K）、转速（1000-2800rpm）、扭矩（10-80Nm）
- 基于 z-score 异常度的综合风险评分（0-100）
- 绿 / 黄 / 红三级质量缺陷风险预警
- 雷达图可视化各参数偏离程度

## OEE 计算模型

| 指标 | 公式 | 计算规则 |
|------|------|----------|
| Availability | (计划时间 - 停机损失) / 计划时间 | 故障停机 30 分钟/次；刀具磨损每 200 分钟触发 45 分钟换刀 |
| Performance | 实际转速 / 标准转速 | 标准转速 1500 rpm，上限截断为 1.0 |
| Quality | (总产量 - 缺陷数) / 总产量 | TWF/HDF/PWF/OSF 任意为 1 即判定为缺陷件 |

计划时间：1440 分钟（24 小时/台/日）

## 数据源

UCI AI4I 2020 Predictive Maintenance Dataset — 10,000 条真实数字化车间运行日志，包含设备转速、扭矩、温度、刀具磨损及五类失效模式标签。
